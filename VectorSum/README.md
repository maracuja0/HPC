# Лабораторная работа 1. (VectorSum)

--------------------------

Реализация данной лабораторной работы включает в себя функции вычисления суммы вектора на `CPU` и `GPU`. На `CPU` используется базовый подход: последовательный обход массива с накоплением суммы в переменной.
На `GPU` применена редукция — каждый поток суммирует пары соседних элементов,
постепенно сокращая число активных потоков. Обмен данными происходит через `shared-memory`. Финальная сумма по всем блокам получается
через итеративные вызовы редукции.
