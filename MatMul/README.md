# Лабораторная работа 0. (MatMul)

--------------------------

Умножение на CPU: Функция `matmul_cpu` применяет тройной цикл для перемножения квадратных матриц.

Умножение на GPU: Функция `matmul_gpu` задействует CUDA для параллельных вычислений на видеокарте. CUDA-ядро распределяет
элементы выходной матрицы по потокам; индексы потоков вычисляются с помощью blockIdx, blockDim и threadIdx.
Параллелизация достигается за счет сетки CUDA из блоков и потоков, где каждый поток независимо считает один элемент.
